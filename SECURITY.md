# Security and privacy

This repository is documentation, generated HTML, and image assets. Its primary
security concern is accidental publication of private data or credentials.

Please do not open a public issue for a suspected secret, private path, private
project identifier, or personal information. Use GitHub's private vulnerability
reporting or contact the repository owner privately.

Include the affected file and enough context to locate the material. Do not copy
the suspected secret into additional channels. The maintainer will remove the
content from the current tree, assess Git history, rotate credentials when
needed, and publish a corrected clean history.

For ordinary factual errors, broken links, or rendering problems, use a normal
issue or pull request.
