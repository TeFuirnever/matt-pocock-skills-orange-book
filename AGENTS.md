# Repository Agent Guide

## Scope

This repository is a public, fixed-version Chinese handbook for Matt Pocock's
public Skills repository. Keep changes documentation-focused and reviewable.

## Sources Of Truth

- Numbered Markdown files under `chapters/` and `labs/` are the authoritative
  content sources. Preserve their lexical order.
- `book.md`, `html/index.html`, `html/book.html`, `html/labs/`, and
  `html/assets/` are generated by `npm run build`.
- `research/` holds bounded evidence notes. Claims in the book must preserve
  each note's source, date/version, and inference limits.
- Upstream behavior is fixed to commit
  `6654f6b60cd9d5be8b54c6fafe44346dabeb3b76`.
- Treat `in-progress` Skills as experimental, not stable interfaces.

## Public Boundary

- Use synthetic, anonymous desktop UI examples.
- Do not add private project names, source code, local user paths, credentials,
  raw chat transcripts, or internal release information.
- Preserve third-party attribution, font licenses, and image provenance.
- Add only final public Azhou PNG assets under `assets/azhou/`. Local review
  candidates are not repository or Pages content and must not be described as
  published illustrations.

## Required Verification

Run `npm ci` after dependency changes and `npm run check` before completion.
Do not edit generated editions directly; update `chapters/`, `html/print.css`,
`html/site.js`, or the build pipeline instead.
Excalidraw changes must retain the editable scene and refreshed SVG/PNG exports.
