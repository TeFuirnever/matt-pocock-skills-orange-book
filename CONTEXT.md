# Orange Book Content Model

This context defines the reader-facing and evidence-facing concepts that keep a fixed-source handbook teachable, releaseable, and historically trustworthy.

## Language

**Release Edition**:
A public, immutable release of the Orange Book identified by its release version and reader-facing scope.
_Avoid_: upstream version, commit version, page version

**Evidence Baseline**:
The internal pinned upstream snapshot and first-party evidence records that bound the factual claims in one Release Edition.
_Avoid_: public version, reader version

**Azhou Editorial System**:
The reader-facing editorial and visual layer that translates traceable public material into executable, verifiable Chinese engineering actions. It makes evidence visible, leaves trade-offs to people, and requires replayable delivery evidence.
_Avoid_: upstream author, evidence source, decision maker

**Reading Path**:
A reader-oriented route through one Release Edition, such as a beginner, advanced, or practice route.
_Avoid_: version, edition

**Practice Gate**:
A core checkpoint with three to five learner actions, a 45-minute limit, and one reusable handoff artifact.
_Avoid_: long Lab, mini project

**Micro-practice**:
A non-blocking, chapter-local action that takes no more than ten minutes and produces an immediately observable result.
_Avoid_: Practice Gate, Lab

**Capstone**:
A 60–150 minute integration exercise that combines completed Practice Gates into one reviewable delivery.
_Avoid_: Practice Gate, chapter exercise

**Historical Snapshot**:
A still-readable Release Edition that no longer receives content updates.
_Avoid_: current edition, supported edition
