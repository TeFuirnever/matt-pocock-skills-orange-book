# Code of conduct

This project is a learning resource. Discussions should make it easier for
beginners and maintainers to examine evidence, correct mistakes, and improve the
book.

## Expected behavior

- Be specific about the text, diagram, source, or behavior under discussion.
- Separate factual corrections from preferences.
- Give newcomers enough context to act on feedback.
- Respect privacy and do not request private code, credentials, or transcripts.
- Accept corrections when fixed-version evidence contradicts a claim.

## Unacceptable behavior

Harassment, personal attacks, discriminatory language, threats, deliberate
misrepresentation, publishing private information, and repeated disruption are
not accepted.

Maintainers may edit or remove contributions and restrict participation when
needed to enforce these boundaries. Report conduct concerns privately to the
repository owner.
