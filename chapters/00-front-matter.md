# Matt Pocock Skills 橙皮书

**从传统开发到 AI 协作开发：37 个 Skills 的心智模型、作者一手材料与 UI 客户端实战**

> 这不是一份命令清单。真正要学会的是：什么时候应该停下来问问题，什么时候应该做原型，什么时候必须先让测试变红，以及怎样把一次对话变成可跨会话交付的工程证据。
